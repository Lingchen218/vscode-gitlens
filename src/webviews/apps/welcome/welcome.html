Launchpad

使用 Launchpad 将所有 GitHub 拉取请求引入统一的、可操作的列表，以更好地跟踪工作进行中、待处理、审查和更多内容。保持专注并采取行动，确保团队不会被阻止。 了解更多

Code Suggest Code Suggest

解放你的代码审查，摆脱 GitHub 的限制性、评论性反馈风格。像在 Google-doc 上建议更改一样，建议代码更改，从你已经编码的地方开始——你的 IDE 和项目中的任何东西，不仅仅是 PR 中更改的代码行。 了解更多

云补丁 Cloud Patches

通过创建从你的工作进行中、提交或暂存生成的链接，轻松安全地与你的队友或其他开发者共享代码更改。使用云补丁来协作早期反馈，以最小化重做和简化工作流程。 了解更多

Worktrees

通过最小化分支之间的上下文切换，高效地多任务处理，让你可以轻松地在存储库的不同分支上工作。避免在需要审查拉取请求时中断你的工作进行。只需创建一个新的工作树并将其打开一个新的 VS Code 窗口，所有这些都不会影响你的工作进行。

GitKraken (GK) Workspaces

利用工作区轻松将多个存储库组合在一起，从任何地方访问，简化工作流程。只需为自己或与团队共享（即将在 GitLens 中推出），以便更快地入职和更好地协作。 了解更多

Visual File History

快速查看文件的演变，包括何时进行更改、更改的大小以及谁进行了更改。使用它快速找到对文件影响最大的更改，或者与文件更改相关的人。

集成

简化工作流程并快速获得见解，通过自动链接问题和拉取请求，跨多个 Git 托管平台包括 GitHub、GitHub Enterprise , GitLab、GitLab 自托管 , Gitea、Gerrit、Google Source、Bitbucket、 Bitbucket Server、Azure DevOps 和自定义服务器。

所有集成提供自动链接，而与 GitHub 和 GitLab 的丰富集成提供详细的悬停信息，用于自动链接、拉取请求、分支和提交之间的相关性，以及用户头像以添加上下文。
